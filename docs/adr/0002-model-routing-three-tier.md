# ADR-0002: 模型路由 — 规则先行 → 本地小模型（可插拔）→ API 大模型

日期：2026-11-19 · 状态：已接受

## 约束

- 开发机**纯 CPU / 集成显卡**：本地生成模型吞吐有限
- 成本敏感：全套评测预算 ≤ ¥30（DeepSeek 量级价格）
- 数据合规：客户消息含 PII（手机号/订单号），不宜原样出境到第三方 API

## 决策（三级路由）

1. **规则层**：能确定的不进模型（关键词命中、格式校验、简单 FAQ）——零成本零延迟
2. **本地层（可插拔）**：embedding（bge-small-zh）/ rerank（bge-reranker-base）/ **PII 脱敏**（正则+NER）固定本地跑；可选 Ollama+Qwen3-1.7b 承担短文本分类/抽取
3. **API 层**：复杂生成走 DeepSeek/GLM（OpenAI 兼容）；评测 Judge 用**另一家**模型避免同源偏差

书锚点：§1.2.3 如何选择模型、§7.6 模型选型与成本分析、§3.1.8 日志脱敏。

## 代价

- 三级路由增加一跳复杂度：需要路由决策可观测（记入 Trace，W4 落地）
- 本地/云端结果一致性：脱敏还原机制需测试覆盖（W4）

## 证据计划（W5）

同批任务「全 API vs 三级路由」的成本与延迟对比表，进评测报告与简历量化句。
